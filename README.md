# Illegacy

## Транспилятор для автоматизированного перевода legacy-кода на актуальные ЯП

### На данный момент реализуется перевод исходного кода, написанного на ЯП C, на Python

**Синтаксические конструкции:**

- [x] Объявление и вызов функции
- [x] Объявление переменных (в Python интерпретируются как `var = None`)
- [x] Перевод операторов (в т.ч. `i++`/`++i` интерпретируется как `i+=1`, `i--` аналогично)
- [x] Массивы интерпретируются как списки
- [x] Конструкция `if{}else if{}else` интерпретируется как `if: ... elif: ... else`
- [x] `Switch case` интерпретируется как `match case`
- [ ] Комментарии в исходном коде на данный момент вырезаются
- [ ] Цикл `for`
- [ ] Цикл `do-while`
- [ ] `enum`
- [ ] `struct`
- [ ] `union`
- [ ] Использование стандартных функций
- [ ] Тернарный оператор
- [ ] Ссылки и указатели
