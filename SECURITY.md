## Сообщение об уязвимостях

Безопасность проекта **illegacy** является приоритетом. Если вы обнаружили уязвимость безопасности, пожалуйста, сообщите нам ответственным образом.

### Как сообщить об уязвимости

**Не создавайте публичные issue** для уязвимостей безопасности. Вместо этого используйте один из следующих способов:

### Что включать в отчёт

Для максимально быстрого рассмотрения предоставьте следующую информацию:

- **Тип уязвимости** (например, XSS, инъекция, утечка данных и т.д.)
- **Полный путь уязвимости** — пошаговое описание воспроизведения
- **Доказательство концепции** (PoC) — код или скриншоты
- **Возможное воздействие** — что может сделать злоумышленник
- **Рекомендации по исправлению** (если есть)
- **Ваш контакт** для обратной связи

### Чего ожидать

1. **Подтверждение получения** — мы ответим в течение **48 часов** с подтверждением получения вашего отчёта
2. **Оценка** — наша команда оценит уязвимость в течение **5 рабочих дней**
3. **План исправления** — мы сообщим вам о планируемом сроке исправления
4. **Исправление** — после выпуска патча мы уведомим вас
5. **Публичное раскрытие** — через **30 дней** после выпуска исправления (если вы не попросите иное)

### Процесс обработки уязвимостей

```
1. Сообщение получено → 2. Подтверждение → 3. Оценка → 4. Исправление → 5. Релиз → 6. Раскрытие
     (0-2 дня)           (1-2 дня)      (3-7 дней)   (7-30 дней)  (релиз)   (30 дней после)
```

## Безопасность зависимостей

Проект использует следующие инструменты для обеспечения безопасности зависимостей:

- **cargo audit** — проверка Rust зависимостей на известные уязвимости
- **npm audit** — проверка JavaScript зависимостей

### Регулярные проверки

Мейнтейнеры проекта регулярно проводят проверки безопасности:

```bash
# Проверка Rust зависимостей
cargo install cargo-audit
cargo audit

# Проверка JavaScript зависимостей
npm audit
```

## Рекомендации по безопасности для пользователей

### Сборка из исходников

При сборке проекта из исходников убедитесь:

1. Вы используете **актуальную версию Rust** (1.70+)
2. Все **системные зависимости обновлены**
3. Вы проверяете **контрольные суммы** при загрузке бинарных файлов

### Запуск приложения

- Не запускайте приложение с правами администратора/root без необходимости
- Используйте актуальные версии операционной системы
- Регулярно обновляйте приложение до последней версии

## Известные ограничения

На данный момент известны следующие ограничения безопасности:

- **Парсинг ненадёжного кода** — не рекомендуется парсить код из непроверенных источников
- **Выполнение кода** — сгенерированный код должен проверяться перед выполнением

## Баунти программа

На данный момент программа вознаграждений за обнаружение уязвимостей (bug bounty) **не активна**. Мы рассматриваем возможность её запуска в будущем.
